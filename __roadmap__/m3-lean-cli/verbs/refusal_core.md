## Step 1: Fix the scope, then register the codes
**Goal**: The enums this leaf codes are listed from the oracle, and `codes.toml` holds their rows and the allowlist of the enums that are not an author's, before any impl exists.
**Implementation Logic**:
1. Read `__roadmap__/m3-lean-cli/refusal_scope.tsv`. The rows this leaf owns are those with this leaf in the owner column. Expected modules: `resolve`, `experiment`, `runner` (with `runner/evidence`), `isolation`, `store`, `supervise`, `frames`, the harness crates, and the binary's `CliError`. The code today also holds author-reachable enums in `manifest/` (`VerdictError`) and `trace/` (`NormaliseError`), which the plan names for no leaf: if the tsv does not assign them, report it to the coordinator and do not code them. Today's counts by file are the check on the tsv: `resolve` `ConfigError` 6, `ResolveError` 6, `PreflightError` 1; `experiment` `InputError` 2, `SurfaceError` 5; `runner` `PlanError` 10, `ExecError` 5, `CatalogError` 6, `CensusError` 3, `EvidenceError` 2; `isolation` 13 enums; `store` `StoreError` 12; `supervise` `SuperviseError` 8, `HookError` 2; `frames` `FramesError` 4; harness `DriverError` 5, `ReaderError` 3, `CommandSpecError` 3, `ClaudeCodeError` 1. A count that differs is a tsv defect: report it.
2. Write each author variant's row by hand in its own section of `docs/contract/codes.toml`, the sections the skeleton pre-created (read the file for their names): code `<surface>.<reason>` (for example `experiment.setting_as_factor` for `PlanError::SettingAsFactor`), side, surface, enum and variant. Reasons name the cause, never the function. A code once written is never renamed.
3. An enum or variant that is not an author's goes in `[internal]` with its enum and a one-line reason; its fallback code is `candler.internal`. An enum the tsv gives to a later leaf stays out of both and is listed in R1's pending list (Step 2). Never put an author-causable variant in `[internal]` to make R1 pass.
4. A variant that wraps another error (`#[error(transparent)]` over `#[from]`) owns no row and is marked `delegates`; the wrapper's side is its own.
**Deliverables**: `docs/contract/codes.toml`: the rows of this leaf's sections and the `[internal]` rows
**Consistency Checks**: `git diff --quiet HEAD -- crates && git diff --numstat HEAD -- docs/contract/codes.toml | awk '$2!=0{b=1}END{exit b}'` (expected: PASS)
**Commit**: `docs(cli): register the codes of the core's refusals`

## Step 2: Code the enums, guard R1 first
**Goal**: Every enum Step 1 listed implements `Refusal` through `refusal_table!`, `catalog()` lists them with the schemas' rows, and R1 holds.
**Implementation Logic**:
1. Write R1 first, in `crates/candler-core/tests/guard_refusal_codes.rs`, and see both tests red against the Step 1 rows, with no impl:
   - `r1_every_error_enum_is_coded_or_internal`: scans every `crates/*/src/**/*.rs` for `thiserror::Error` types (struct or enum, `pub` or not) and requires each to be in `codes.toml` (any section) or `[internal]`, or in the test's pending list. Each author variant's side is not `candler`, as the tsv classes it. The pending list holds only the enums the tsv gives to `refusal_late` and to M4; `refusal_late` empties it.
   - `r1_every_variant_code_equals_its_row`: for every row of `refusal::catalog()`, the code, side and surface equal its `codes.toml` row. Codes are unique and match `^[a-z]+(\.[a-z_]+)+$`. `codes.toml` is read; nothing is generated from the code.
2. `<module>/refusal.rs` beside each enum, with the `mod refusal;` line in the module's `mod.rs`: `refusal_table!` for the enum (exhaustive, no wildcard; each row also carries the `when` and `at` sentences the contract pages print, one line each, written for an agent), and the hand-written `path()` where a variant names a document location (`PlanError::SettingAsFactor { path }` gives the pointer to the factor; a variant that names none gives `None`). Harness crates get `crates/candler-harness/src/refusal.rs` and `crates/candler-harness-claude-code/src/refusal.rs`, which compile because both depend on `candler-schemas`. An existing inherent `code()` (`accounting.rs:32`, `guard.rs:62`) is a different thing: do not rename it, and call the trait method as `Refusal::code(&e)` where both are in scope.
3. `crates/candler-core/src/refusal.rs` (`pub mod refusal;` in `lib.rs`): `pub fn catalog() -> Vec<CatalogRow>` concatenating `candler_schemas::refusal::catalog()` and each module's rows, in the order of the tsv; and `pub fn find<'e>(error: &'e (dyn std::error::Error + 'static)) -> Option<&'e dyn Refusal>`, which walks the `source()` chain and downcasts to each coded type in the catalog. The walk lets the binary find a refusal carried inside `CliError::Failed` without editing a verb that other leaves own.
4. Run R1 green. No `jobs/`, `evaluation/` or `import/` file is touched.
**Deliverables**: `crates/candler-core/src/refusal.rs`: `catalog`, `find`; `crates/candler-core/src/{resolve,experiment,runner,isolation,store,supervise,frames}/refusal.rs`: the impls and `ROWS`; `crates/candler-harness/src/refusal.rs`; `crates/candler-harness-claude-code/src/refusal.rs`; the `mod refusal;` lines; `crates/candler-core/tests/guard_refusal_codes.rs`: `r1_every_error_enum_is_coded_or_internal`, `r1_every_variant_code_equals_its_row` (docs with `Guards:`, `Oracle:`, `Bite:`)

## Step 3: Render a refusal as `refusal/1`
**Goal**: A verb's failure prints as one `refusal/1` line on stderr under `--error-format json`, with exit 2, and prints as today under `text`.
**Implementation Logic**:
1. Write R2 first (`crates/candler/tests/guard_cli_refusal.rs`, `r2_…`), through the real binary run from a temp directory with the PATH-fake docker of `tests/support/cli_run.rs`, and see it red. Rows, each compared to a hand-written record (`code`, `side`, `path`, exit 2, one line, stdout empty):
   - a malformed plug-in manifest: reached today through `evaluate --plugin … --suite …`; the code comes from the schemas' `EvaluationError` that `find` meets in the source chain;
   - an experiment that varies a setting as a factor (`experiment.setting_as_factor`);
   - an unknown `request.*` key (Step 4 turns this row green; here it is on the pending list);
   - a suite whose params the plug-in's schema refuses, and a missing plug-in directory: both are `RegistryError` and `EvaluateError`, which belong to `refusal_late`. They are rows of the pending list that `refusal_late` turns on. They stay in this file, so the five rows R10 names exist from this leaf on.
2. `crates/candler/src/commands/refusal.rs`: `CliRefusal`, the binary's own author-causable refusals, coded through `refusal_table!` (`NoStore`, `RetiredSetting { path }`, and Step 4's `UnknownRequestKey { path }`), with their rows in `codes.toml`'s `[experiment]` or `[config]` section as the tsv says. `render(error: &CliError, format: ErrorFormat) -> String`: `Text` is `candler: {error}` exactly as today; `Json` builds a `RefusalRecord` from `refusal::find` (code, side, path), `message` from the error's text, `causes` from its `source()` chain, and `file` where the verb read one. An error with no refusal in its chain is `candler.internal`, side `candler`. One line per error.
3. `commands/mod.rs`: `CliError::refused_by<E: Refusal + Error + Send + Sync + 'static>(e: E) -> Self` beside `CliError::failed`, which keeps its bound; a variant that carries the boxed refusal and prints as `refused: {e}`, so the text of a converted site equals the text of the `refused(...)` it replaces. `CliError::with_file(self, path)` records the file. Convert the sites of `common.rs`, `run.rs` and `preflight.rs` that an author can cause (`no store`, the retired setting, the resolver's failures); leave `CliError::Refused { reason }` for the sites other leaves own: they report as `candler.internal` until their leaf converts them.
4. `main.rs`: the single print site calls `render` with the parsed `--error-format`; exit codes stay 0, 1, 2.
5. R2 green except the pending rows.
**Deliverables**: `crates/candler/src/commands/refusal.rs`: `CliRefusal`, `render`; `crates/candler/src/commands/mod.rs`: `CliError::refused_by`, `CliError::with_file`; `crates/candler/src/commands/common.rs`, `crates/candler/src/commands/preflight.rs`, `crates/candler/src/commands/run.rs`: converted sites; `crates/candler/src/main.rs`: the render call; `crates/candler/tests/guard_cli_refusal.rs`: `r2_…`; `docs/contract/codes.toml`: the `CliRefusal` rows
**Consistency Checks**: `cargo nextest run -p candler --no-tests=fail -E 'test(/^r2_/)|binary(guard_cli)|binary(guard_cli_run)' && git diff --numstat a26fe53 -- 'crates/candler/tests/guard_cli*.rs' | awk '$2!=0{b=1}END{exit b}'` (expected: PASS)
**Commit**: `feat(cli): print a refusal as refusal/1 under --error-format json`
