## Step 1: The inventory and its guard
**Goal**: `platform_inventory.toml` lists every source file of the workspace that uses a unix-only API, each with its use and its Windows counterpart, and Q1 keeps the list equal to the code.
**Implementation Logic**:
1. Write `crates/candler-core/tests/guard_platform_seam.rs` first with its two guards, and an empty `platform_inventory.toml` (the header comment only), and see the set guard fail naming the 21 files. Each guard doc carries `Guards:`, `Oracle:` and `Bite:`.
   - `q1_unix_apis_stay_inside_the_inventory`: walks `crates/*/src/**/*.rs` and `crates/*/build.rs` from `CARGO_MANIFEST_DIR/../..` with `std::fs` (the test must not depend on `git`). A file uses a unix-only API when a line that does not start with `//` holds `std::os::unix`, `rustix::` or `libc::`. The set of such paths must equal the inventory's, both ways: a new user fails, and a stale entry fails.
   - `q1_every_inventory_entry_names_its_use_and_a_windows_counterpart`: each `[[file]]` has `path`, a non-empty `uses` array and a `windows` text that is not empty, not `todo` and not `tbd`.
2. Write the inventory by hand. Format: `[[file]]` tables with `path` (workspace-relative), `uses` (what it calls) and `windows` (the counterpart). The files today, by group:
   - `supervise/`: `signal.rs` (kill and process-group signals, `/proc` reads), `platform.rs` (`rustix::process::Pid`; start time from `/proc` or `libproc`), `reap.rs` (`getpgid`), `spawn.rs` and `stop.rs` (`Signal`, `ExitStatusExt`), `mod.rs` (`Signal::KILL`);
   - `jobs/`: `lock.rs`, `slots.rs`, `events.rs` (`flock`), `runtime/session.rs` (`setsid`, the subreaper role), `runtime/reap.rs` (`waitpid`), `runtime/sweep.rs` (`Signal`);
   - `isolation/`: `container/mod.rs` (`getuid`, `getgid` for the mount owner), `image.rs` (`flock`);
   - `runner/`: `plan.rs` (`flock` on the experiment lock), `exec/mod.rs` (`PermissionsExt`);
   - `store/`: `blob.rs` (`PermissionsExt`), `index.rs` (`flock`), `sync.rs` (`fsync`, `fdatasync`);
   - `evaluation/context/materialise.rs` (`OpenOptionsExt`, `PermissionsExt`), `import/read.rs` (`PermissionsExt`, inside a `cfg(unix)` function that has a `cfg(not(unix))` twin; it is `candler-core`, so it stays as it is).
   The counterparts are those of R10 D7's table: Job Objects (`TerminateJobObject`, `CTRL_BREAK`) for the process groups and signals; a held process handle for the pid-reuse rule; `LockFileEx` for `flock`; `DETACHED_PROCESS` for `setsid`; `FlushFileBuffers` for `fsync`; ACLs or no mode bits for `PermissionsExt`; no counterpart is needed for the subreaper and the marker sweep, because a Job Object contains every descendant. Regenerate the path list with the command in Step 1's check, then write each entry's text yourself.
3. Green the two guards. Show their bites and report them: add a `use std::os::unix::fs::PermissionsExt as _;` to `commands/evaluate.rs` (red), clear one `windows` text (red). Neither edit is committed.
**Deliverables**: `crates/candler-core/tests/guard_platform_seam.rs`: `q1_unix_apis_stay_inside_the_inventory`, `q1_every_inventory_entry_names_its_use_and_a_windows_counterpart`; `crates/candler-core/tests/vectors/platform_inventory.toml`: 21 `[[file]]` entries
**Consistency Checks**: `git grep -l -E 'std::os::unix|rustix::|libc::' -- ':(glob)crates/*/src/**' ':(glob)crates/*/build.rs' | sort | diff - <(grep '^path = ' crates/candler-core/tests/vectors/platform_inventory.toml | sed -E 's/^path = "(.*)"$/\1/' | sort) && cargo nextest run -p candler-core --no-tests=fail -E 'test(/^q1_unix_apis/) | test(/^q1_every_/)'` (expected: PASS)
**Commit**: `test(repo): freeze the unix-only platform surface in an inventory`

## Step 2: One `compile_error!`, no stray stub
**Goal**: The binary refuses to build for a non-unix target with one message that names WSL2, and the `cfg(unix)` gates and the `cfg(not(unix))` stub that compile nowhere are gone.
**Implementation Logic**:
1. Write the third Q1 guard first in `guard_platform_seam.rs` and see it fail: `q1_the_binary_states_its_targets_with_one_compile_error` reads `crates/candler/src/main.rs` and requires one `compile_error!` under `cfg(not(unix))` whose text holds `WSL2`. Its doc carries `Guards:`, `Oracle:` (the text of R10 D7) and `Bite:` (the macro removed). Then, in `crates/candler/src/main.rs`, add under the crate docs: `#[cfg(not(unix))] compile_error!("candler builds for Linux and macOS only; on Windows run it inside WSL2, where it is Linux");`. This is the binary's only `cfg(not(unix))` (G-platform), and the guard goes green.
2. In `commands/evaluate.rs`, delete the `#[cfg(unix)]` on `run` and the whole `#[cfg(not(unix))]` `run` with its `#[expect(clippy::unused_async)]`. In `commands/common.rs`, delete the seven `#[cfg(unix)]` lines (the imports of `Registry`, `register_evaluation_steps`, `EventSink`, `Supervisor`, `EventPayload`, `RunKey`, and the gates of `evaluation_resolver`, `StderrSink` and its `impl`). Why: with the `compile_error!` they are inert on unix and misleading on the rest. The gates are not an API use, so Q1 does not see them.
3. Check `common.rs` for anything else the gates hid: `evaluation_resolver` and `StderrSink` are plain unix code once the gates go; no other item needs a change. The two L1 leaves that edit `common.rs` (`refusal_core`, `evaluate_body`) are cut after this one merges, so their hunks are trivial; `evaluate_verb` edits `evaluate.rs` later still.
4. `candler-core/src/import/read.rs:264` is core and is left. The `cfg(not(unix))` arms of `tests/` files (`#![cfg(unix)]` inner attributes) are tests and are left.
5. Where the Windows target is installed (`rustup target list --installed`), `cargo check -p candler --target x86_64-pc-windows-msvc` prints the WSL2 message first. It is not required: the target is not installed here.
**Deliverables**: `crates/candler-core/tests/guard_platform_seam.rs`: `q1_the_binary_states_its_targets_with_one_compile_error`; `crates/candler/src/main.rs`: the `compile_error!` under `cfg(not(unix))`; `crates/candler/src/commands/evaluate.rs`: `run` without a gate and without its non-unix twin; `crates/candler/src/commands/common.rs`: without `#[cfg(unix)]`
**Consistency Checks**: `test "$(git grep -c 'cfg(not(unix))' -- 'crates/candler/src/**' | awk -F: '{s+=$2}END{print s+0}')" -eq 1 && ! git grep -n 'cfg(unix)' -- 'crates/candler/src/**' && cargo check --workspace --all-targets && cargo nextest run -p candler-core --no-tests=fail -E 'test(/^q1_/)'` (expected: PASS)
**Commit**: `build(repo): refuse to build the binary for a non-unix target`
