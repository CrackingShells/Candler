## Step 1: Read a legacy results folder into a typed model
**Goal**: One pass reads the folder into a model in which every file is a source, an artifact, a stream, or a skipped entry with its reason.
**Implementation Logic**:
1. `ImportRules` (`import/rules.rs`), built by the caller; the core names no domain (I1):
   - `format: NameToken`, the label written into every `ImportRecord`;
   - `harness: HarnessRule {name: NameToken, version_pointer: String}`, a JSON pointer into the first line of a run's stream (`/claude_code_version` for this corpus);
   - `treatment: TreatmentRule::new(pointer: String, resolved: FieldPath)`: a JSON pointer into `experiment.json` whose value is `<name>@<tag>` (`/plan/skill_version`), and the dotted path of the cell's resolved treatment version (`resolved_skill_version`), so that the core names neither; a dotted key in that path is refused;
   - `instrument: NameToken` (`htn_creator_scripts`), its version and digest taken from `PROVENANCE.json` `pinned`;
   - `snapshots: Vec<SnapshotRule {kind: NameToken, pointer: String}>`, JSON pointers into `PROVENANCE.json` holding a sha256 (`catalog` at `/catalog/sha256`);
   - `markers: Vec<MarkerRule {pattern: regex::Regex, code: MarkerCode}>`, tried in order on a `not_measured` row's evidence; `MarkerCode`: `Fixed(NameToken)` or `Capture(String)`, a named group of the pattern;
   - `suite_kind: NameToken`, the `kind` of every synthesised suite entry;
   - `metadata: Vec<FieldPath>`, the manifest values copied into each context projection.
2. `LegacyFolder::read(root: &Path, rules: &ImportRules) -> Result<LegacyFolder, ImportError>`. The layout is the legacy format's: `PROVENANCE.json` and `expectations.jsonl` at the root; one directory per cell holding `experiment.json`, `progress.jsonl` and `contamination_catalog.jsonl`; `_run_cache/<config>/run-N/` with `outputs/`, `agent_stream.jsonl.gz`, `agent_stderr.txt` and `run_complete.json`; `eval-K-<title>/<config>/run-N/` with `eval_metadata.json`, `timing.json`, `grading_summary.json` and `metrics.json`; and `eval-K-grading.json` files found by name under a run's eval directories.
3. Every file read becomes a `SourceFile {path: RelPath, sha256: Digest, bytes: Vec<u8>}`, its path relative to `root`. Files the model does not interpret (`benchmark.json`, `matrix_cell.log`, root-level notes and scripts) are kept as cell or folder sources, so nothing is lost. Only AppleDouble `._*` files, `.DS_Store`, `__MACOSX/` and `shared_<config>/` are skipped, each as `Skipped {path, reason: SkipReason}` (`apple_double`, `finder_metadata`, `archive_metadata`, `shared_inputs`).
4. Refusals (`ImportError`, `thiserror`, each naming the file and the run): a run without `outputs/`; a grading file name found twice; a file that is not valid JSON or JSONL where the format requires it; a path that is not a valid `RelPath`.
**Deliverables**: `crates/candler-core/src/import/rules.rs` (`ImportRules`, `HarnessRule`, `TreatmentRule`, `SnapshotRule`, `MarkerRule`, `MarkerCode`); `crates/candler-core/src/import/read.rs` (`LegacyFolder`, `LegacyFolder::read`, `LegacyCell`, `LegacyRun`, `SourceFile`, `Skipped`, `SkipReason`); `crates/candler-core/src/import/mod.rs` (`ImportError`; module declarations only, no re-exports); `crates/candler-core/src/import/legacy.rs` (the legacy format's keys, files and directories, each named once)
**Consistency Checks**: `cargo clippy -p candler-core --all-targets -- -D warnings` (expected: PASS)
**Commit**: `feat(importer): read a legacy results folder into a typed model`

## Step 2: Map legacy runs to manifests and integrity
**Goal**: Each legacy run becomes a `RunManifest` whose `comparable` follows R01's field table, so its cell digest is the one a live run of the same cell would compute.
**Implementation Logic**:
1. `map_runs(&LegacyFolder, &ImportRules) -> Result<Vec<MappedRun>, ImportError>`, `MappedRun {key: RunKey, manifest: RunManifest, run: usize}` (`run` indexes the folder's runs).
2. `comparable.values`: every leaf of `experiment.json` under `plan`, `provenance` and `resolved_skill_version` becomes a dotted `FieldPath` (objects are descended; any other value, an array included, is a leaf); a `null` leaf has no value. `plan.out_dir` and `schema_version` go to `import`, not to `values`. Every value gets source `imported {file: experiment.json}` in `sources[]`, the null ones `unrecorded` (I12: same path set).
3. `comparable.harness`: `rules.harness.name` and the version read at `version_pointer` from each run's first stream line; the versions of a cell must agree, else refused. `comparable.treatment` from `rules.treatment`. `comparable.snapshots` from `rules.snapshots`. `comparable.inputs`: `timing.json` `copied_inputs[]` as `{kind: role, digest: sha256:<hex>}`; the copies within a cell must agree, else refused. `environments` is empty.
4. `measured`: each `eval_metadata.json` `provenance.*` leaf whose `experiment.json` value is `null`, with source `imported {file: <run-relative path>}`; the 13 copies of a run must agree, else refused. `factors`: `execution::varying_paths` over the folder's cells. `experiment`: `execution::experiment_digest` of the cell digests. `import.requests`: for a valid run, its one outcome file `{evaluator, request_id}`. `run`: `(cell digest, N, 1)`.
5. `ended_at`: `run_complete.json` `completed_at`; `started_at`: `ended_at` minus the elapsed seconds between the run's `run_start` and `run_complete` events in `progress.jsonl`, in milliseconds; absent when an event is missing.
6. `integrity`: `PROVENANCE.json` `runs[].original_integrity.verdict`, matched to the run by `(cell, config, run)`: `clean` and `incomplete` → `valid`; `contaminated` → `invalid {reason: input_leak}`; any other value is refused. The run's line in `contamination_catalog.jsonl` must carry the same verdict, else refused; a run with no line there, or a cell without the file, counts as `clean` in the catalog. `import`: `{format, base_commit: corpus.base_commit, legacy_integrity: <the original_integrity block>, sources[]}`, the sources sorted by path.
**Deliverables**: `crates/candler-core/src/import/manifest.rs` (`map_runs`, `MappedRun`)
**Consistency Checks**: `cargo clippy -p candler-core --all-targets -- -D warnings` (expected: PASS)
**Commit**: `feat(importer): map legacy runs to manifests and integrity`

## Step 3: Map legacy grading to outcome records
**Goal**: Every row of a valid run becomes one `OutcomeRecord` that carries the legacy fact unchanged and marks with `{legacy}` only what the clean model cannot state.
**Implementation Logic**:
1. `map_grading(&LegacyFolder, &MappedRun, &ImportRules) -> Result<Vec<OutcomeRecord>, ImportError>`; an invalid run returns no record. Rows come from `expectations.jsonl`; `blocked_by` and the evidence come from the run's `eval-K-grading.json`, whose status must equal the row's.
2. One `match` over the legacy status with no `_ =>` arm, an unknown status refused. `score`/`max_score` → `weight`, omitted when it equals the status default (pass 1/1, fail 0/1, blocked 0/1), dropped on `not_measured`; a `pass` weighing `0/0` → cause `{legacy: zero_weight}`. `blocked_by` → cause `{artifact: <path>}`. The value's JSON token decides its kind: an integer literal → `count`, a literal with `.` or an exponent → `number`, a string → `text`. `not_measured` → `{legacy: <code>}` from the first matching `rules.markers` entry, else `{legacy: unrecorded}`. A legacy `not_applicable` → `{reason: not_applicable_to_arm}`. `role` is the row's. Evidence: one `{note}` holding the legacy evidence text, or `no legacy evidence`.
3. Identity: evaluator `pinned.describe` (`name@version`), never a per-run field (the per-run `eval_infra` values name the original 0.3.4 grader); instrument `{name: rules.instrument, version: <the describe version>, digest: git:<pinned.commit>, dirty: pinned.dirty}`. `request_id`: a UUIDv7 whose 48-bit time is `regraded_at.finished` in milliseconds and whose 74 random bits are the first 74 bits of `sha256(<run key path form> 0x00 <evaluator name@version>)`, 12 into `rand_a` and 62 into `rand_b`.
4. `suite_entry_digest`: `SuiteEntry::digest` of the synthesised entry `{kind: rules.suite_kind, params: {scale, text, tier}, role, depends_on: []}`, the params from the expectation in `eval-K-grading.json`. `context_digest`: `RunContext::context_digest` of the projection with `artifacts` = every file under `outputs/` (path relative to `outputs/`, sha256), `snapshots` and `inputs` = the manifest's, `metadata` = the `rules.metadata` paths' values.
5. `tests/guard_legacy_mapping.rs`: the six B tests of the Success Gates, with the corpus's rules built in `tests/support/legacy_rules.rs` (test code may name the domain) and the oracle included with `#[path]`. Then delete the leaf's scaffolding and write the bite record.
**Deliverables**: `crates/candler-core/src/import/grading.rs` (`map_grading`); `crates/candler-core/tests/guard_legacy_mapping.rs`; `crates/candler-core/tests/support/legacy_rules.rs`; `crates/candler-core/tests/public_surface.rs` (the import items)
**Consistency Checks**: `cargo nextest run -p candler-core -E 'binary(guard_legacy_mapping) | binary(public_surface)' && ! git grep --untracked -n 'mod scaffold' -- crates/candler-core/src/import` (expected: PASS)
**Commit**: `feat(importer): map legacy grading to outcome records`
