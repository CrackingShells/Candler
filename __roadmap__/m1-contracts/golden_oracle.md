## Step 3: Derive every expected outcome row independently
**Goal**: A test-support module turns raw corpus files into expected rows and run facts without any Candler code.
**Implementation Logic**:
1. `tests/oracle/mod.rs`, included by test binaries with `#[path]`: `expected_rows(corpus: &Path) -> Vec<ExpectedRow>` and `expected_runs(corpus: &Path) -> Vec<ExpectedRun>`, reading `serde_json::Value` only, never `candler_schemas` or `candler_core` types.
2. `ExpectedRow {cell, run_n, expectation_id, role, status, value, weight, cause}` as plain strings and integers, built by one `match` over the legacy status with no `_ =>` arm (an unknown status panics with its location):
   - `score`/`max_score` → weight `num/den`, omitted when equal to the status default (pass 1/1, fail 0/1, blocked 0/1), dropped on `not_measured`; `0/0` on a pass → cause `legacy: zero_weight`;
   - `blocked_by` from the run's `eval-K-grading.json` → cause `artifact: <path>`;
   - the number token decides the value kind: an integer literal → `count`, a literal with `.` or an exponent → `number`, a string → `text`;
   - `not_measured` → `legacy: <code>` from the `TIER_D_REPLAY … reason=` marker in the evidence, `zero_mappings`, or `unrecorded`; legacy `not_applicable` → `reason: not_applicable_to_arm`.
3. `ExpectedRun {cell, run_n, integrity: valid | invalid(input_leak), harness_version, measured: Vec<(path, value)>}` from `PROVENANCE.json` `runs[].original_integrity.verdict`, the stream's init line, and `eval_metadata.json` `provenance.*` where `experiment.json` has `null`. Invalid runs yield no rows.
4. `tests/guard_oracle_mini.rs` (`guard_oracle_mini`, not ignored) and `tests/guard_oracle_aggregates.rs` (`oracle_aggregates`, `#[ignore]`, panics if `CANDLER_GOLDEN_CORPUS` is unset).
**Deliverables**: `crates/candler-core/tests/oracle/mod.rs` (`expected_rows`, `expected_runs`, `ExpectedRow`, `ExpectedRun`); `crates/candler-core/tests/guard_oracle_mini.rs`; `crates/candler-core/tests/guard_oracle_aggregates.rs`
**Consistency Checks**: `cargo nextest run -p candler-core -E 'binary(guard_oracle_mini)' && CANDLER_GOLDEN_CORPUS="$GOLDEN" cargo nextest run -p candler-core --run-ignored only --no-tests=fail -E 'test(oracle_aggregates)'` (expected: PASS)
**Commit**: `test(importer): derive every expected outcome row independently`

## Step 4: Pin identity and digest vectors from Python
**Goal**: Digests and ids that the Rust code will compute are pinned by another engine from R01's text.
**Implementation Logic**:
`tests/oracle/vectors/gen_vectors.py`, run with `uv run --with rfc8785`, writes TOML vector files whose header names the generator and the `rfc8785` version:
- `cell_digest.toml`: six `comparable` objects built by R01 §Run manifest and §Golden corpus (lists sorted, unique), each with its `sha256:` digest and a `cell` key naming its mini-corpus cell or `invented-<n>`: every mini-corpus cell, and invented cells up to six; for each, a shuffled twin (same content, lists in another order, for the builder to sort) and a nuisance twin (a different `sources`, `secrets`, `measured`, timestamp and host).
- `context_digest.toml`: four projections per R01 §Digests of a request (empty lists, one of each, unsorted input, metadata with nested values).
- `suite_entry_digest.toml`: three entries, each with a twin differing only in `id`, `evaluator` and `deadline_ms`.
- `catalog_content_digest.toml`: two hand-written `tool-catalog-snapshot/1` documents differing only in `captured_at`, and a third differing in one tool, each with the digest of its RFC 8785 form without `captured_at`.
- `request_id.toml`: the three mini-corpus runs: run key path form, evaluator `htn-creator-eval@0.4.2`, `regraded_at.finished`, and the UUIDv7 built per R01 §Golden corpus.
Then delete the leaf's scaffolding and write the bite record.
**Deliverables**: `crates/candler-core/tests/oracle/vectors/{gen_vectors.py,cell_digest.toml,context_digest.toml,suite_entry_digest.toml,catalog_content_digest.toml,request_id.toml}`
**Consistency Checks**: `cd crates/candler-core/tests/oracle/vectors && uv run --with rfc8785 python gen_vectors.py --check` (expected: PASS)
**Commit**: `test(importer): pin identity and digest vectors from Python`
